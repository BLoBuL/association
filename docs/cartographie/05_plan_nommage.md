# Plan de nommage des fonctions

Generation: 2026-04-20

## Convention cible

- Helpers internes metier: `association_<action>_<objet>`.
- Actions SPIP: `action_<nom>[_dist]` (convention native, ne pas renommer vers `association_*`).
- Autorisations: `autoriser_<faire>_<objet>[_dist]`.
- Formulaires CVT: `formulaires_<nom>_{charger,verifier,traiter}[_dist]`.
- Balises/criteres/filtres: `balise_*`, `critere_*`, `filtre_*` (conventions natives).

## Regle de tri avant renommage

1. Si la fonction est un point d'entree SPIP (`action_*`, `autoriser_*`, `formulaires_*`, `balise_*`, `critere_*`, `filtre_*`, `exec_*`, `genie_*`), la garder telle quelle.
2. Si la fonction est un helper metier interne, proposer un alias `association_*` puis migration progressive.
3. Ne pas casser les signatures publiques stables declarees dans `AGENTS.md`.
